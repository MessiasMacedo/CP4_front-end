
# 🌱 E-commerce EcoTrend - Front-End 

## 📖 Descrição do Projeto

O **EcoTrend** é um e-commerce especializado em produtos sustentáveis e ecológicos, desenvolvido com o objetivo de promover um estilo de vida mais consciente e sustentável.

O projeto consiste no desenvolvimento de uma interface web responsiva para uma loja virtual, utilizando **HTML, CSS, CSS Grid e Bootstrap**. A aplicação apresenta produtos organizados por categorias, páginas de produtos, filtros, formulário de contato e componentes visuais que facilitam a navegação e proporcionam uma experiência de usuário mais agradável.

---

## 🎯 Objetivo do Projeto

Desenvolver uma **interface responsiva de um e-commerce especializado em produtos sustentáveis**, utilizando tecnologias e ferramentas voltadas para desenvolvimento Front-End.

O projeto busca aplicar conceitos de:

- Estruturação de páginas web;
- CSS Grid;
- Design responsivo;
- Componentização utilizando Bootstrap;
- Personalização de estilos;
- Organização de produtos em diferentes categorias;
- Criação de formulários;
- Desenvolvimento de uma interface visualmente coesa.

---

## 🚀 Tecnologias e Ferramentas Utilizadas

- **HTML:** Estruturação das páginas e conteúdos do site.
- **CSS Grid:** Organização das seções e produtos em layouts de grade.
- **Bootstrap:** Framework CSS utilizado para responsividade e componentes.
- **Font Awesome:** Biblioteca de ícones para elementos da interface.
- **Google Fonts:** Biblioteca de fontes gratuitas utilizada para estilização dos textos.

## 🧩 Componentes do Projeto

### 1. 🏠 Página Inicial (Home)

A página inicial apresenta os principais elementos da loja:

* **Header:** Barra de navegação contendo logo, menu e ícone de carrinho.
* **Banner:** Carousel desenvolvido com Bootstrap para destacar promoções e produtos em destaque.
* **Seções de Produtos:** Produtos organizados em diferentes categorias utilizando cards do Bootstrap.

---

### 2. 🛒 Página de Categorias

A página de categorias apresenta os produtos disponíveis em um layout organizado em grid.

Cada produto possui:

* Imagem;
* Nome;
* Preço;
* Botão **"Adicionar ao Carrinho"**.

Também são disponibilizados **filtros laterais**, utilizando colunas do Bootstrap, permitindo filtrar os produtos por:

* Preço;
* Tipo de produto;
* Marca.

---

### 3. 📦 Página de Detalhes do Produto

A página de detalhes apresenta informações mais completas sobre um produto selecionado.

Entre as informações apresentadas estão:

* Imagem em destaque;
* Nome do produto;
* Descrição;
* Preço;
* Outras informações relevantes sobre o produto.

---

### 4. 📩 Página de Contato

A página de contato possui um formulário estilizado utilizando Bootstrap.

O formulário contém campos para:

* Nome;
* E-mail;
* Assunto;
* Mensagem.

O objetivo é permitir que os clientes entrem em contato com a loja de maneira simples e organizada.

---

### 5. 🦶 Footer

O rodapé apresenta informações importantes sobre a loja, incluindo:

* Links para redes sociais;
* Informações de contato;
* Políticas da loja;
* Outras informações institucionais.

## 🔧 Tarefas de Desenvolvimento

### 📐 Estruturação de Grid

Organização das seções e componentes em uma estrutura de grid utilizando **CSS Grid e Bootstrap**, garantindo uma distribuição adequada dos elementos na página.

### 📱 Responsividade

Garantir que o layout seja responsivo para diferentes tamanhos de tela, realizando ajustes em:

* Grids;
* Margens;
* Espaçamentos;
* Tamanhos de fonte;
* Organização dos componentes.

### 🧩 Uso de Componentes do Bootstrap

Aplicação de componentes disponibilizados pelo Bootstrap, como:

* Cards;
* Carrosséis;
* Formulários;
* Grid responsivo;
* Barra de navegação.

A utilização desses componentes facilita o desenvolvimento e contribui para manter uma aparência visual consistente.

### 🎨 Estilização Personalizada

Sobrescrita e personalização dos estilos padrão do Bootstrap para adaptar a aparência do site à identidade visual do **EcoTrend**, criando uma interface única para a loja.
